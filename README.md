# WaveCore

WaveCore is an experimental browser engine written from scratch in Rust.

The project intentionally does not use Chromium/Blink, WebKit, Gecko, or Qt WebEngine as its rendering engine.

## v0.1 goals

- HTML tokenizer/parser
- DOM tree
- basic CSS parser and cascade
- block layout
- simple display list / renderer
- tests for each engine stage

## Status
