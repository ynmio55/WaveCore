⚡ WaveCore Phase 3 Architecture — Multi-Process & Partial Repaint
ก้าวสำคัญสู่ Browser Engine ระดับโปรดักชัน
แยก Browser Process และ Render Process ผ่าน IPC Message พร้อมระบบ CORS Preflight, Cache-Control Semantics (max-age/no-store) และ Partial Repaint ด้วย Damage Rectangles เพื่อประสิทธิภาพ 60/120Hz ที่แท้จริง
📡 Multi-Process IPC
จำลอง IsolatedRenderHost และแชนเนลสองทาง BrowserEndpoint ↔ RenderEndpoint แยก IO / Filesystem ไม่ให้แตะต้องโดยตรง
🔒 CORS & Cache-Control
ตรวจจับ Access-Control-Allow-Origin ข้าม Origin และประมวลผล max-age / no-store / 304 revalidation ใน HttpCache
⚡ Damage Pipeline
กรองคำสั่งวาดเฉพาะพื้นที่ที่เกิดการเปลี่ยนแปลง (paint_damage) และส่งขึ้นหน้าต่างผ่าน present_damage โดยไม่ล้างจอใหม่ทั้งหมด
🚀 Zero Idle Redraw (Compositor Ready)
ระบบตรวจจับความเปลี่ยนแปลงเฉพาะเมื่อมี Event หรือ Damage Rects ทำให้ลดการกิน CPU และ Memory Bandwidth ได้อย่างมหาศาล
