WaveCore Browser Engine (Stages 1–10 Complete)

เครื่องยนต์เว็บเบราว์เซอร์สถาปัตยกรรมโมเดิร์น เขียนด้วยภาษา Rust 100%

การทดสอบภาษาไทยระดับสมบูรณ์ 100% (HarfBuzz OpenType Shaping)

การจัดวางวรรณยุกต์และสระภาษาไทยลอยถูกต้องตามหลักอักขรวิธี เช่น ที่ นี่ ปี่ ป้า กิ๊ก กุ้ง นํ้าพริก ผัดไทย ปลากระพงทอด

ทดสอบวรรณยุกต์ซ้อนสระบนและล่าง: ญี่ ปู่ ฟื้น มนุษย์ ปฏิทิน คริปโทเคอร์เรนซี ฐิติ

ทดสอบวรรณยุกต์กับพยัญชนะหางยาว: ป่า ป้า ป๊า ป๋า ฝ่า ฝรั่ง ฟ้า ฟ้อง — สระและวรรณยุกต์หลบหางพยัญชนะอย่างถูกต้องสวยงาม

สถานะการพัฒนาระยะที่ 1 ถึง 10 (Roadmap Stages 1-10)

• 1. DOM + HTML: Parser พร้อม Entity decoding (© • &) & Void tags

• 2. CSS Parser: Specificity cascade, Tag, Class, ID, Selector commas & Inline styles

• 3. CSS Box Model: Margin, Padding, Border, Width/Height, Auto-flow

• 4. Text Engine: HarfBuzz OpenType shaping, Tone mark lifting & Emoji 🚀🌊✨

• 5. Renderer: Anti-aliased text rendering, Border boxes, Color fills, Image blitting

• 6. Window/Compositor: Real-time 60 FPS viewport window, scrolling, and resize

• 7. Networking: HTTP/HTTPS client (TLS, redirects, gzip) via wavecore-net

• 8. Navigation: History stack, Back/Forward/Reload, URL resolution

• 9. Images: PNG/JPEG/WebP/GIF decoding & alpha blending

• 10. Input: Mouse click hit-testing on links, keyboard navigation shortcuts, mouse wheel scrolling
